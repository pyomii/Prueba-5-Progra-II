# Prueba-5-Progra-II

1. Requisitos
- **Java (JDK)** instalado.
- **NetBeans** (compatible con `build.xml` y `nbproject`)[cite: 1].

2. Cómo abrir y ejecutar
1. Descomprime el archivo y abre la carpeta `Prueba5` como proyecto en **NetBeans**[cite: 1].
2. Revisa `config.txt` si necesitas ajustar algún parámetro antes de iniciar[cite: 1].
3. Compila y ejecuta `Prueba5.java`[cite: 1].

3. Cómo usar la aplicación
- **Vista principal (`VistaPrincipal` / `VentanaPrincipal`):** Desde aquí accedes a las funciones principales del sistema[cite: 1].
- **Análisis y estadísticas:** Selecciona o ingresa la ruta a analizar para obtener las métricas generadas[cite: 1].
- **Gestión de archivos:** Utiliza las opciones de gestión para trabajar con archivos o nodos según lo disponible en pantalla[cite: 1].
- **Errores de ruta:** Si ingresas una ruta inválida, el sistema mostrará el aviso correspondiente sin cerrarse de forma abrupta[cite: 1].
- **Registro (`bitacora.log`):** Consulta `bitacora.log` en la raíz del proyecto para revisar el historial de ejecución[cite: 1].
